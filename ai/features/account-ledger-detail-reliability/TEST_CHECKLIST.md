- [ ] **G2-1 — Three consecutive authenticated direct navigations:** in the supported live Next dev/Turbopack setup, make three consecutive *direct/full-document* requests to a representative, authorized in-tenant `/account-ledger/<id>` detail URL. Use the same valid authenticated session and representative test record for each request. For every attempt, require the expected detail response (normally HTTP 200 and the expected route content; not a login redirect, pending request, or error) to complete in **under 120 seconds**, measured from request start through response completion. A request still pending at 120 seconds fails. Record each duration and outcome separately, including failures; do not average a failed attempt away. Preferred performance is **cold first completion <=30 seconds** and **each warm completion <=10 seconds**. Record which attempt was cold/warm and do not treat preferred targets as substitutes for the 120-second hard bound.
- [ ] **G2-2 — Correlate compile and response:** for each request, record a sanitized timestamp, redacted route path, request type, destination origin/port, exact Next dev process/revision, browser request start/completion/status/timing, and the matching terminal compile-start/compile-completion/error output. Note whether compilation completed before response, and if it did not, retain the result as a pending/erroring request rather than attributing it to a specific stage without evidence. Never capture/share cookies, authorization headers, tokens, customer/fiscal payloads, or secrets.
- [ ] **G2-3 — Minimal-route versus branch-route comparison:** in an isolated disposable copy with the same Node/Next version, Turbopack command, dependencies/lockfile, relevant non-secret environment, machine, and equivalent server conditions, compare (a) the authenticated representative URL with only the detail page replaced by a minimal static Server Component and (b) the unchanged branch detail route. - [ ] **G2-4 — Report shared slow routes separately:** report `/account-ledger` and any lightweight same-process control-route timing as separate observations, including whether they meet the relevant threshold. Do not use the already-reported slow list route as proof of the detail cause or as an acceptable detail response.
